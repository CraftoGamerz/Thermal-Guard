# Backend structure

Existing SQLite: snapshots(key TEXT PK,payload TEXT,saved_at TEXT); event_records(id TEXT PK,payload TEXT); reviews(id INTEGER PK,event_id TEXT,status TEXT,classification TEXT,note TEXT,analyst TEXT,created_at TEXT); areas(id TEXT PK,name TEXT,bbox TEXT,created_at TEXT). Reviews reference retrieved events logically; prepared statements and WAL remain. Analysis adds analysis_runs(id TEXT PK,payload TEXT,created_at TEXT), retaining completed/failed job metadata and report (no uploaded raw CSV). Model artifact written under data/analysis/<UUID>/model.json.

Existing routes: GET /api/health, GET /api/events?source&days&bbox&mode; GET/POST /api/events/:id/reviews; GET /api/context?lat&lon (OSM, never asserted facility identity); GET/POST /api/areas; DELETE /api/areas/:id. Shared token (optional locally), same-origin checks and rate limits remain.

New routes: POST /api/analysis/jobs accepts {source: NOAA20|NOAA21|SNPP,days:1|2|7,bbox:[w,s,e,n],csv?:string}; max 2 MB CSV, bounded total JSON body. Returns 202 {id,status,stage,startedAt}. GET /api/analysis/jobs/:UUID returns job {id,status,stage,startedAt,finishedAt?,elapsedMs,error?,result?}. Status queued/running/completed/failed. One concurrent heavy job; requests above capacity return 429. Poll only the known job. Failed jobs never return substitute scores. Reject replay input. Use fixed executable/script paths and spawn without shell; JSON via stdin, timeout, output limit, child cleanup.

Training is a seven-day regional NASA request for selected sensor; input/output provenance includes quality counters and stale flags. Train first UTC days, calibrate penultimate UTC day, test final UTC day (minimum 4 days; >=100 training and >=20 calibration/test rows). FRP target transformed log1p; features never include FRP, a label derived from FRP, weather or guessed land cover. Required complete radiometry/geometry rows only. Calibrate positive log residual percentile against calibration residuals; this is an empirical ranking, not calibrated fire probability. Observations on training/calibration dates are explicitly marked. Held-out metrics use unseen final day and compare a training median baseline. Nearby history considers only strictly earlier UTC days within 5 km from available feed, not a 30/365-day baseline. No-detection is not no-fire.

Input validation bounds (prototype guardrails, not official NASA quality flags): I4/I5 brightness 150–500 K, scan/track 0.01–5 km, valid global coordinates, D/N flag; FRP finite and nonnegative. Missing values are excluded, not filled. At most 50,000 training and 15,000 scoring rows per run. Features outside the training min/max are explicitly flagged even when within validation bounds. Python worker receives JSON only via stdin, supports cancellation on server close, returns bounded JSON, and cannot execute user-supplied paths or commands. Hyperparameters: 140 trees, depth 4, eta 0.06, row/column sampling 0.9, CPU hist method, seed 42, two threads. These settings are fixed before temporal evaluation.

Result: model version/split/metrics/importance/domain; rows {id,eventId?,lat,lon,acquiredAt,observedFrp,expectedFrp,residualPercentile,split,baseline,flags}; input/source metadata; real processing timings; source classification remains unverified. Uploaded CSV never replaces NASA training and has unverified provenance. Persisted reports retain source timestamps; each model artifact has an adjacent exact normalized training.json matching the report digest. Serialize JSON finite numbers only. Local user reviews are not ML labels. Reports/model artifacts are retained until manually archived; repeated runs consume local disk. Interrupted jobs return a restart/rerun message. The final test UTC day may be partial; no completed-day assumption is made.
